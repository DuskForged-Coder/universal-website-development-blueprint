# Code of Conduct

## Our commitment

We aim to make participation in this project welcoming, respectful, and constructive.

## Expected behavior

- Be respectful and considerate.
- Critique ideas, not people.
- Explain disagreements with evidence and clarity.
- Welcome questions and different experience levels.
- Respect privacy and do not publish another person's personal information.

## Unacceptable behavior

Harassment, discrimination, personal attacks, intimidation, doxxing, and sustained disruptive conduct are not acceptable.

## Reporting

Report conduct concerns privately to the repository owner through the contact method listed on the owner's GitHub profile. Do not post sensitive personal information in a public issue.

Project maintainers may remove, edit, or reject contributions that violate this code.
