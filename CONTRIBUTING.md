# Contributing

Thank you for considering a contribution to the Universal Website Development Blueprint.

## Before contributing

- Read the README and the relevant architecture guide.
- Open an issue before substantial changes so the scope can be discussed.
- Keep the blueprint technology-neutral. Label framework- or vendor-specific material as an example.
- Explain the requirement behind a proposed module; avoid adding complexity without a use case.

## Pull requests

1. Describe the problem and proposed change.
2. Identify affected diagram pages and documentation.
3. Keep terminology consistent across the Draw.io diagram and Markdown guides.
4. Check internal links and Mermaid syntax.
5. Note any security, privacy, accessibility, or operational implications.

## Scope

This repository provides educational architecture guidance. Contributions should not imply that a diagram or checklist guarantees security, compliance, or production readiness.
